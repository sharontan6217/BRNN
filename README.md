# BRNN
This script is part of the paper of "Genetic Algorithm Based Bi-directional Recurrent Neural Network for LIBOR Prediction" accepted by iC3I-2019 , IEEE. The copyright is authorized to IEEE. 
This script is proven to be workable for forecasting time seriese dataset with stable and nice performance, although you can still observe the defect when simulating the complex wave shape or turning point.
The optimier part is removed and you can add it if you would like.
A simple BiRNN model is added for applications.
